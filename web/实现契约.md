# 实现契约

用户目标：将现有LLM知识库设计为可一键打开的前端网站；README提供中英文切换，删除更新原则和固定上海8点说明。

网站通过Astro静态生成部署到GitHub Pages，展示7模块、45主题、135知识点、6学习路径与核心指南。已有Markdown与JSON是唯一内容来源；不手写第二套主题正文。保留v1.0标签和发布清单。

数据和路由：topics的稳定ID生成/read/<id>/；模块/modules/<id>/；路径/paths/<slug>/；指南/guides/<slug>/。GitHub Pages前缀/llm-systems-wiki/必须只附加一次；内部Markdown链接指向可展示文章/模块/路径/指南时转换为站内路由，其他仓库文件转为GitHub/blob/main路径，外部http(s)、mailto及#锚点保留，不允许javascript/data/vbscript等可执行scheme。源码下载使用原仓库链接。

搜索：全局搜索同时覆盖主题标题、知识点标题、模块名、学习目标与正文纯文本；NFKC和大小写归一。所有非空空白分隔词均需命中；按标题、知识点、目标、全文的相关性排序，等分保持源顺序。模块过滤与关键词组合，空输入返回该模块全部主题；零结果提供清空入口。结果链接可直接打开。搜索弹窗支持Ctrl/Cmd+K、Escape和焦点约束。

阅读：渲染Markdown正文、数学、代码高亮和Mermaid图；不显示frontmatter。文章有面包屑、章节目录、源码入口、知识点数、前后主题导航与收藏按钮。章节ID应与正文内锚点一致。所有原始HTML和可执行URL需要安全处理，不能让论文/代码文本变成可执行页面脚本。

交互：模块筛选、列表/卡片视图、收藏过滤、学习路径详情、亮/暗主题、移动端侧栏均真实可用。收藏和主题仅存在本机localStorage，存储受限时仍可继续阅读；不存学习者个人信息到服务器。UI语言切换支持中文/English界面；原有主题正文仍为中文并提示，不伪称全库已翻译。

README：README.md与README.en.md互相链接，均有在线站点按钮、内容范围、快速开始、贡献与许可；删除更新原则及固定更新时间承诺。

工程：新代码在web/独立目录，构建产物不提交。Node>=22，npm锁版本；单进程构建页面并限制内存。CI保留既有知识库检查与826Python测试，新增静态网站类型/构建检查；Pages通过GitHub Actions部署到公有URL。一键入口指向实际已部署站点，不交付仅本地localhost地址。

验收：内容路由覆盖正确、搜索/过滤与链接转换有针对性单测；类型检查、静态构建通过；桌面和移动端真实浏览器检查搜索、模块、路径、文章公式/代码/图、主题、收藏、语言切换与站内链接；没有水平溢出、遮挡及空白页。结构和视觉检查分开报告。
