# 网站开发

展示层直接读取仓库内的Markdown和knowledge清单，Astro生成静态页面，部署于GitHub Pages项目子路径。正文不在前端目录重复维护。

需要Node.js 22及以上版本。进入web目录，使用`npm ci`安装锁定依赖；`npm run dev`启动开发，`npm run check`检查类型，`npm run build`生成dist，`npm run preview`查看构建结果。构建使用页面并发1；大型机器上也不增加默认并发。

`npm test`检查搜索、路由、正文转换和客户端交互；构建完成后用`npm run test:built`检查生成页面与知识清单的对应关系。两类测试均以单进程执行，GitHub Pages工作流通过后才部署。

搜索覆盖标题、知识点、学习目标与正文，支持模块过滤；所有空白分隔词都需命中，NFKC和大小写归一。内部文章链接转为站点路由，其余文件链接回GitHub。数学、代码和图继续来自原始Markdown。

收藏与主题保存在本机浏览器；存储不可用时不影响阅读。中英切换覆盖导航与操作界面，原有知识正文仍为中文。README.md和README.en.md提供完整的两种仓库介绍。

测试与交互验收依据见[实现契约](实现契约.md)及仓库贡献指南。自动部署只在检查通过后发布；固定更新时间不是网站功能或内容承诺。
