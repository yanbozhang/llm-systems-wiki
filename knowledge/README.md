# 知识清单

这个目录供网站和检查工具使用。普通读者可直接打开[知识点索引](../docs/知识点索引.md)或[阅读网站](https://yanbozhang.github.io/llm-systems-wiki/)。

| 文件 | 管理的对象 |
|---|---|
| modules.json | 七个模块及学习轮换 |
| topics.json | 基础主题、正文位置、教学示例与学习目标 |
| units.json | 知识点与公式、函数、图、来源的绑定 |
| capabilities.json | 能力目标和可提交的学习成果 |
| claims.json | 关键声明、来源版本与适用条件 |
| relations.json | 前置知识和相关阅读关系 |
| frontiers.json | 七模块研究进展、截止日期、基础主题与来源 |

来源身份的唯一清单是[sources.json](../sources/manifest/sources.json)。不要手工维护另一份正文副本；修改正文时同步受影响的清单和引用，流程见[贡献指南](../CONTRIBUTING.md)。
