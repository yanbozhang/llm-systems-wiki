# 初版范围与验收

本页保留v0.1历史范围；当前能力见[学习体系升级](../wiki/changes/学习体系升级.md)。

v0.1 以可阅读的 Git 知识包为交付单位。技术方案中的完整持续编纂系统分阶段实施，本版不把规划中的能力写成已运行服务。

| 要求 | 本版交付 | 边界 |
|---|---|---|
| 六模块学习基线 | 六个概览与二十四个主题 | 非穷尽知识百科 |
| 三条学习路径 | 入门、系统工程、Agent 开发 | 无自动学习效果判定 |
| 来源与声明 | 二十九份来源、二十四条核心声明、六十四条关系 | 不是逐句完整知识图谱 |
| 原始材料 | 固定论文版本、地址、文本指纹和短摘 | 未镜像全文，不保证原站失效后的恢复 |
| 每日维护 | GitHub 定时来源巡检、主题轮换、独立候选分支 | 深度编纂仍需阅读与复核 |
| 发布与版本 | Git 提交、初始清单、变化记录 | 由 Git 提交提供版本原子性，无外部索引切换 |
| 检索与阅读 | GitHub Markdown 导航与仓库搜索 | 无额外网站、向量检索或问答后端 |
| 质量检查 | 离线结构检查与维护脚本单测 | 不证明每项研究结论正确 |
| 个人学习 | 独立笔记目录与记录模板 | 私人内容默认不提交 |

## 验收方式

检查主题主页面、来源版本引用、先修关系无环及相对链接。维护脚本通过针对重复来源、解析失败、状态写入顺序、日期边界和无效元数据的测试；实际结果由发布时的检查记录说明，不能仅依据本页宣称通过。

首版论文与框架材料只做相关章节阅读和编纂，未运行 GPU 训练、推理性能基准、GUI 基准或第三方 Wiki 应用。学习练习的数值是写明假设的推导，不是实测收益。

## 后续里程碑

完成一次真实来源变更的专题编纂闭环后，增加声明版本历史与失效传播；连续完成六模块轮换后，评估模型辅助编纂的成本与错误模式；有明确漏召回样本后，再评估全文增强、向量或图检索。服务化应以读者需求与可测收益为前提。
