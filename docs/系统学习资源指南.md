## 怎样使用逐点映射

以下路线按[主题清单](../knowledge/topics.json)和[知识点清单](../knowledge/units.json)生成，覆盖每个主题的三个知识点。先看每主题的课程起点，再进入正文相应“知识点一/二/三”，最后阅读对应函数和源码。起点表示本库建议的学习入口，不宣称课程逐项讲过该方案或该函数；涉及具体算法的论文与官方依据在主题正文中逐点列出。

表内“源码参照”指已登记、实际读取的固定commit文件，精确原函数和读取范围可在[来源清单](../sources/manifest/sources.json)的locator、reading_scope回查。教学函数名属于本库，不冒充上游函数名；如半衰期排序、语义支持审计、权限门控等，还包含明确标注的教学策略。读者应对照正文理解相同处与简化处，不能把两份代码当作等价实现。

每行交付一份小记录：输入与假设、手算预期、源码定位、一个反例、实际验证方式。先独立计算，再看教学代码。作者给出输入与预期，维护者组织必要的独立验证；这张映射表不包含课程作业、模型或设备实验结果。复习与内容更新的具体顺序见[持续更新指南](持续更新指南.md)。

## 七模块逐点路线

### 模型网络：4主题、12知识点

先从张量、条件概率和链式法则补基础，再把注意力、头布局、位置与归一化连成一次前向计算。CS336的基础构建路线用于组织作业；PyTorch SDPA教程用于辨认数学运算与优化算子的差别。完成本模块应能解释形状和索引，尚不要求GPU性能实验。

### 训练：4主题、12知识点

先用PyTorch基础与Hugging Face LLM Course理解训练工作流，再按预训练、SFT、偏好目标、策略优化推进。CS336用于目标、数据和对齐的学习顺序；精确梯度及默认损失分支回到论文和TRL/PEFT源码。每次练习先写有效token分母，再算损失。

## 跨模块复习如何验收

完成逐点练习后，每次选择一条跨模块链，写清相邻环节的输入输出和没有被验证的假设。下面三条路径使用既有主题，不要求安装完整框架。

| 路径 | 可交付的小产物 | 验证与边界 |
| --- | --- | --- |
| GQA → KV缓存 → 连续批处理 → 推理系统性能基准 | 同一请求集合的缓存字节表、物理块表、调度时间线、TTFT/TPOT与联合达标表 | 先核算单位和预算，再核对分位数约定；算术成立不证明GPU吞吐，正式MLPerf还需精度与提交规则 |
| 来源版本 → BM25/RRF → 上下文选择 → RAG评测 | 固定文档版本、候选名次、入选上下文、参考声明与回答声明支持表 | 同时检查漏召回、预算截断和裁判错误；引用链接可点击不能替代内容支持 |
| 任务契约 → 工具调用 → 检查点恢复 → Agent任务评测 | 动作身份表、未知结果回读记录、状态快照、预算内任务终态表 | 恢复事件历史不自动回滚外部副作用；模型或协议结束不等于独立任务通过 |

复习时先合上正文重做一个原例，再改变一个条件：换头分组、重复SEARCH、删除证据、缺少result、把同一调用重复送达等。能说明为什么结果变化，比复述项目名称更能暴露理解缺口。个人记录绑定unit ID、page_version和来源版本；课程观看进度、教学测试状态与真实实验状态分开保存。更多项目组织见[跨模块实践项目](跨模块实践项目.md)。

## 借鉴的是学习方法

D2L把公式、图示、代码和练习放在一起；CS336公开大纲按基础构建、系统分析、规模、数据与对齐组织作业。本库据此为所有知识单元增加目标、前置、具体推导或案例、实践产物与掌握标准，而不只在页末加链接。依据：[D2L](https://zh.d2l.ai/)与[CS336公开大纲](https://stanford-cs336.github.io/spring2025/)。

Hugging Face课程提供分层入口、自测与实践，OpenCompass文档明确先完成一次完整评测、再学习和扩展组件。本库因此提供不同起点的学习路径，并要求每轮学习形成一个能复核的小产物。依据：[Agents Course](https://huggingface.co/learn/agents-course/unit0/introduction)与[OpenCompass](https://opencompass.readthedocs.io/en/latest/)。

FSDL课程把LLMOps、产品、检索和工具连接到应用，Ragas区分端到端、组件及业务指标。本库据此增加跨模块项目与Benchmark模块，要求改进既解释机制，也说明测量口径。依据：[FSDL](https://fullstackdeeplearning.com/llm-bootcamp/spring-2023/)与[Ragas指标概览](https://docs.ragas.io/en/stable/concepts/metrics/overview/)。

这些是本库的设计取舍，尚未通过用户学习实验验证其效果。课程原作业和代码按原站约定使用，本库不复制完整课程或代交作业答案。
