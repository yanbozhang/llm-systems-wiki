# 共同基础

开始前应能读懂张量形状、条件概率、交叉熵、梯度和基本实验记录。这里给出最小自测，不要求先掌握全部深度学习理论。

| 基础 | 要能解释 | 自测 |
|---|---|---|
| 张量与矩阵乘法 | batch、序列、特征维各代表什么 | [B,T,d] 乘 [d,k] 后是什么形状 |
| 概率与 softmax | logits 如何变成归一化分布 | 给所有 logits 加相同常数会改变 softmax 吗 |
| 交叉熵 | 为何最大似然可转成负对数损失 | 正确类别概率从 0.1 到 0.5，损失如何变化 |
| 自动微分 | 前向、梯度、参数更新各做什么 | 梯度累计与增加 batch 的联系和条件 |
| 分词 | 文本、字符、token 不一一对应 | 同一文本在不同 tokenizer 下长度是否可比 |
| 实验 | 对照组、变化变量、重复与污染 | 为什么同时换模型与引擎无法归因速度变化 |

答案要点：结果形状为 [B,T,k]；共同平移不改变 softmax；自然对数负对数损失由约 2.303 降到约 0.693。其他问题需要说明优化器、归一化和数据处理条件，避免机械等同。

阅读：[Transformer 原论文](https://arxiv.org/html/1706.03762v7)、[Hugging Face 分词器课程](https://huggingface.co/learn/llm-course/chapter6/1)、[语言模型训练课程](https://huggingface.co/learn/llm-course/chapter7/6)。课程用于教学，原论文用于机制定位。
