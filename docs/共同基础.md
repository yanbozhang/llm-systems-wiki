# 共同基础

共同基础为七模块提供数学、编程和实验语言。先完成下面的小例子，再进入主题；不需要等全部理论学完才开始，但遇到缺口应回到对应基础。

## 三个手算例子

矩阵例子：A=[[1,2],[3,4]]、x=[1,0]，Ax=[1,3]。把[B,T,d]乘以[d,k]会得到[B,T,k]，不能把最后一维和序列长度混用。

概率例子：二分类真实标签为第一类，预测概率0.5时负对数损失为ln2，预测概率0.25时为ln4。它衡量对真实标签分配的概率；准确率还取决于判定方式，两者不等价。

梯度例子：y=(wx)²，x=2、w=3时，y=36，dy/dw=2wx²=24。自动微分计算这种依赖关系，但学习率、梯度清零和更新时机仍需程序正确组织。

这些是教学推导，未运行训练实验。数学与实践组织参考[D2L](https://zh.d2l.ai/)和[PyTorch基础教程](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)。

## 自测与检查

解释为什么给所有logits加同一个常数不改变softmax；解释为什么相邻文档片段随机分入训练与测试可能泄漏；说明梯度累计在什么条件下接近更大batch，哪些状态或随机操作可能使其不同。

答案要点：softmax共同指数因子约去；相邻片段可能共享信息；梯度累计需要匹配损失归一化和更新频率，而状态、随机性或优化步骤差异仍可能改变结果。对不确定条件应设计对照，不直接宣称等价。
