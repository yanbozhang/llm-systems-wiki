# 跨模块实践项目

下面三个项目将现有知识点组织为可提交的闭环作业。已完成的是45个标准库教学示例及相关正文的编纂；三个端到端项目目前只有具体输入、阶段、预期产物和验收设计，尚未实际运行。真实模型训练、模型调用、GPU服务、真机GUI和产品客户端实验均未执行。

函数是独立教学组件，不保证彼此输入输出可以直接串接；在项目产物中列出明确的字段对应关系，再进行手算或后续独立验证。本轮不新增应用、不运行示例或测试。

## 提交与验收共同约定

每份项目包包含：任务ID和协议版本、能力ID与unit_id、主题page_version、示例文件和函数、冻结输入、独立预期、实际观察及执行状态。未执行时实际观察为空，状态写designed；不能将函数设计预期写成真实模型或设备成绩。

学习者可先完成理解/推导层，再交实践设计；如以后获准做真实实验，必须另存环境、原始输入输出、预算、失败和独立复核证据。教学函数通过测试不自动意味着系统实验通过。

| 项目 | 主要模块 | 闭环要关闭的问题 |
| --- | --- | --- |
| 可追溯知识回答与来源更正 | 知识库、Harness、业务Agent、Benchmark | 来源变化后，哪些回答与练习需要重新核验 |
| 结构、训练与推理预算对照 | 模型网络、训练、推理、Benchmark | 结构或预算变化后，质量与资源结论如何仍可比较 |
| 代码与GUI任务的执行证据闭环 | Harness、业务Agent、Benchmark | 动作结果未知或部分成功时，何时可以认定完成 |

**已完成范围与未执行部分。** 已具备全部教学组件和作业设计；未搭建真实检索服务、调用生成模型或执行真实来源发布更正。外部模型的支持判断准确率、真实检索质量和更新事务一致性仍待实验。

## 复盘如何回到能力目标

将每个未通过项落回[能力地图](能力地图.md)中的具体能力ID和知识点：概念混淆回理解层，公式或分母错误回推导层，输入或状态契约缺失回实践层，证据不足与比较偏差回评估层。只补受影响项，不把一次项目失败判成整个模块都未掌握。

用[学习记录模板](../templates/学习记录模板.md)、[评测协议模板](../templates/评测协议模板.md)和[实验记录模板](../templates/实验记录模板.md)保存产物；未完成的真实实验进入[研究队列](研究队列.md)，不通过修改公共practice_status替代执行证据。
