# 大模型持续学习知识库

这里维护的对象是“可复用的理解”：不仅保存论文链接，还解释问题、方法、条件、演进和证据。知识随新来源修订，学习进度由读者自己记录。

## 知识地图

| 从哪里进入 | 先回答的问题 | 下一站 |
|---|---|---|
| [共同基础](共同基础.md) | 概率、张量、损失和实验口径是什么 | 模型网络 |
| [模型网络](../wiki/modules/模型网络.md) | 输入如何变成 token 分布 | 训练、推理 |

## 三条学习路径

[基础入门路径](../wiki/paths/基础入门路径.md)适合建立全景；[系统工程路径](../wiki/paths/系统工程路径.md)适合推理和服务研发；[Agent开发路径](../wiki/paths/Agent开发路径.md)适合工具、上下文与业务自动化。

每次阅读建议回答三个问题：它解决什么问题，依据在哪，在什么条件下不能这样用。完成练习后把自己的解释写进[学习记录模板](../templates/学习记录模板.md)，而不是只勾选“已读”。

## 版本与证据

主题主身份由 [topics.json](../knowledge/topics.json) 管理，核心声明由 [claims.json](../knowledge/claims.json) 关联来源版本。首版登记的是原文陈述或编纂解释，没有独立复现实验；部分练习是明确假设下的数学推导。

[初始版本](../wiki/changes/初始版本.md)记录本版范围；[研究队列](研究队列.md)记录缺口。开始维护前先读[编纂规范](../schema/编纂规范.md)。
