# 研究队列

队列按学习价值与证据缺口推进。下列条目是待研究项，不是已验证结论或已经启用的功能。

| 优先级 | 模块 | 下一次研究问题 | 预期产物 |
|---|---|---|---|
| 高 | 推理 | FlashAttention 如何减少高带宽存储读写，与 KV 分页在哪个层次互补 | 内核主题与缓存对比 |
| 高 | 知识库 | 一次新来源如何同时修订声明、指南和练习 | 真实专题变更记录 |
| 高 | Harness | 摘要检查点会丢失哪些约束，怎样测恢复质量 | 小任务恢复实验 |
| 高 | 业务 Agent | 如何识别“动作成功但业务未完成” | 终态评估案例 |
| 中 | 模型网络 | MoE 的激活参数、总参数与通信成本如何区分 | MoE 基础主题 |
| 中 | 训练 | On-policy 蒸馏的数据从哪里来，怎样避免术语混用 | 蒸馏方法对比 |
| 中 | 推理 | 推测解码的接受机制和质量条件是什么 | 固定版本论文解读 |
| 中 | 训练 | 分布式训练各并行方式的状态分片与通信是什么 | 并行训练学习页 |
| 中 | 知识库 | 关键词、向量与重排在本库哪些查询上有差异 | 独立检索题集 |
| 后续 | 全部 | 旧声明撤回怎样影响历史阅读与当前回答 | 失效传播设计与验证 |

每项进入实施时记录选题理由、来源范围、时间预算和明确完成条件。来源未知时先找原始论文或官方文档，不凭主题名称补写结论。
