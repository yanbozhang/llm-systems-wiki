# 研究队列

本轮已经完成七模块、35主题、能力地图和课程入口的体系化扩展。后续按内容成熟度与学习价值推进；下列条目是待研究任务，不表示已有实测结论。

| 优先级 | 模块 | 下一步 | 完成证据 |
|---|---|---|---|
| 高 | Benchmark | 用自建小问题集完成一次协议、评分与失败复核 | 固定版本协议、逐题记录和计算过程 |
| 高 | 知识库 | 真实来源更正到主题与练习修订的闭环 | 来源版本、影响链、差异及复查 |
| 高 | Harness | 压缩检查点的约束保留与恢复实验 | 输入、检查点、遗漏与恢复结果 |
| 高 | 推理 | FlashAttention独立主题与正确性对照 | 原始材料、数学说明与边界测试设计 |
| 中 | 模型网络 | MoE、线性注意力、状态空间专题 | 定义、适用条件、机制对比与来源 |
| 中 | 训练 | 分布式训练、蒸馏、On-policy方法 | 训练目标、数据流、资源与独立评测 |
| 中 | 业务Agent | 有重复操作和环境故障的任务组 | 首轮/重试成功及副作用记录 |
| 中 | Benchmark | 长上下文、更多语言与领域分层 | 数据治理与可解释分层结果 |
| 中 | 全部 | 把实践设计逐项升级为真实记录 | 明确版本、资源、结果和失败，禁止只改状态 |

每轮先选择一项能力目标，设定边界与可提交产物，再决定来源数量和实验资源。若证据不足，继续补读或保留问题；不能为了更新频率制造新的技术结论。
