# 能力地图

能力地图将“读懂什么”连接到“提交什么、怎样验收”。1.0 已有七模块、45 个主题、135 个知识点与45个独立标准库教学文件；这里保留28个既有能力ID，每模块设理解、推导、实践、评估四层。它们是学习目标，不表示任何读者已经达成。

权威记录分别见[能力清单](../knowledge/capabilities.json)、[主题清单](../knowledge/topics.json)和[知识点清单](../knowledge/units.json)。每个能力的topic_ids已按代表知识点收窄；unit_ids、example_paths、example_functions、learning_actions与acceptance连接到具体行动和验收。跨模块知识点用于支撑评价，不要求机械学完整个关联模块。

本图共90条能力—知识点绑定，覆盖89个不同知识点；代表单元用于分层入门，其余知识点仍由主题页与专题路径承接。

## 如何使用代表知识点

从一个能力ID开始：先阅读所列知识点，再按函数输入手算正常与边界样例，提交产物，最后逐项对照验收条件。表中的函数链接指向现有教学代码；相同函数名可能位于不同文件，必须连同路径记录。知识点链接进入其所属主题，精确ID由知识点清单解析。

每份产物至少写明能力ID、unit_id、主题page_version、示例文件/函数、输入与独立预期、适用条件、失败反例和实际执行状态。若只做手算或设计，填写“预期/推演”，不得填写模型成绩。示例被执行或通过单测也只验证相应教学规则，不自动验证论文性能、真实设备操作或读者的全部能力。
