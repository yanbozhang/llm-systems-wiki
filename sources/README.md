# 来源资料库

这里保存每份论文、文档、课程和源码的来历。先读主题，再沿文章引用查到资料卡；需要核对原文时，从资料卡进入原站或本地缓存。

本次整理快照（2026-10-25）：352条来源记录、350条已取得的本地快照，去重后315份文件，约59.27MiB。19份选定的上游源码或项目说明已核对MIT/Apache-2.0许可，并随仓库保留许可证及适用的NOTICE。其余全文仍只在本地；两条未取得的来源在各自资料卡中保留失败记录。

## 三个入口

- [按标题查来源](来源索引.md)：面向读者的完整清单，每条都能进入独立目录。
- [按来源ID查目录](library/index.json)：每条来源对应`library/<id>/`，包含资料卡、原登记信息与保存记录。
- [按课程学习](../docs/系统学习资源指南.md)：适合需要连续课程、教材和练习的读者。

## 一个来源目录里有什么

| 文件 | 用来做什么 |
|---|---|
| README.md | 看这份资料讲什么、关联哪些学习主题、实际读到了哪里 |
| source.json | 查原始URL、来源ID、作者版本与原登记文本指纹 |
| archive.json | 查下载结果、取得时间、原始字节指纹和本地保存位置 |
| snapshot/（可选） | 经许可核验后可随仓库公开的材料，同时保留许可证 |

同一论文可能被多个历史来源ID引用，各自保留当时的版本和读取范围。本地相同字节只保存一份，不用重复文件伪装成更多独立证据。

## 原文保存在哪里

原文位于`sources/.local/objects/`，按SHA-256命名；保存记录提供完整相对路径和内容类型。缓存默认不提交Git，也不发布到网站。新克隆没有这些本地文件是正常的，可以按记录重新下载。文件保存成功仅证明取得了相应字节；并不证明论文结论正确、完成全文阅读或完成复现实验。

维护命令在仓库根目录运行：

```bash
python scripts/source_library.py index
python scripts/source_library.py capture --workers 2
python scripts/source_library.py check
python scripts/source_library.py check --local
```

仅下载某条来源可使用`capture --id <source-id> --workers 1`。普通检查适合CI与新克隆；`--local`另外要求本机原文存在且大小、SHA-256吻合。下载失败记录保留在对应目录，历史成功副本不会因后续访问失败而删除。

网页可能只保存了项目入口，论文可能只能取得摘要页。请检查保存记录的`representation`，不要把入口页面当成完整仓库或论文全文。第三方材料保留原许可；本库MIT许可证不授予第三方全文的再分发权。
