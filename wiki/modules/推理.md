# 推理

本模块收录四个核心主题，先理解原理，再做练习并回查原始来源。当前是学习基线，覆盖状态与研究缺口明确保留。

| 主题 | 学习目标 |
|---|---|
| [Prefill与Decode](../topics/Prefill与Decode.md) | 同一个生成请求通常包含处理提示的 Prefill 和逐 token 生成的 Decode。 |
| [KV缓存原理与显存估算](../topics/KV缓存原理与显存估算.md) | KV Cache 保存每层已处理 token 的 K/V，使生成新 token 时复用历史投影。 |
| [缓存分页与连续批处理](../topics/缓存分页与连续批处理.md) | 缓存管理决定有限显存怎样承载动态请求；调度决定哪些请求在同一步获得计算。 |
| [推理框架与性能实验](../topics/推理框架与性能实验.md) | vLLM 和 SGLang 都是可用于学习服务系统的入口。 |

## 模块自测

能否不用查阅正文讲清四个主题之间的区别？能否指出一个需要固定实验条件的结论，并沿来源链接找到对应章节？练习答案是教学要点，不代替自己的推导或实验记录。
