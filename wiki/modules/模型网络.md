# 模型网络

本模块收录四个核心主题，先理解原理，再做练习并回查原始来源。当前是学习基线，覆盖状态与研究缺口明确保留。

| 主题 | 学习目标 |
|---|---|
| [Transformer与自回归生成](../topics/Transformer与自回归生成.md) | 理解一个 token 如何变成下一 token 的分布，是阅读后续训练、缓存与 Agent 文献的共同起点。 |
| [MHA与MQA及GQA](../topics/MHA与MQA及GQA.md) | 注意力头组织决定 Q、K、V 如何分组，也影响解码时 KV Cache 的体积。 |
| [位置编码与RoPE](../topics/位置编码与RoPE.md) | 注意力需要可用的位置信息来区分顺序。 |
| [前馈网络与归一化](../topics/前馈网络与归一化.md) | 注意力完成位置之间的信息汇聚，FFN 在每个位置上做特征变换。 |

## 模块自测

能否不用查阅正文讲清四个主题之间的区别？能否指出一个需要固定实验条件的结论，并沿来源链接找到对应章节？练习答案是教学要点，不代替自己的推导或实验记录。
