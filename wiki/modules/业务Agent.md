# 业务Agent

本模块收录四个核心主题，先理解原理，再做练习并回查原始来源。当前是学习基线，覆盖状态与研究缺口明确保留。

| 主题 | 学习目标 |
|---|---|
| [业务Agent任务闭环](../topics/业务Agent任务闭环.md) | 业务 Agent 的目标是改变外部任务状态。 |
| [GUI定位与执行](../topics/GUI定位与执行.md) | GUI Agent 需要把任务意图映射到当前屏幕中的可操作元素。 |
| [AI代码开发与反馈](../topics/AI代码开发与反馈.md) | 代码 Agent 的任务包括理解仓库、定位问题、修改、验证与交付。 |
| [Agent评测与失败归因](../topics/Agent评测与失败归因.md) | 评测首先固定任务与成功条件，再记录模型、Harness、工具、环境和预算。 |

## 模块自测

能否不用查阅正文讲清四个主题之间的区别？能否指出一个需要固定实验条件的结论，并沿来源链接找到对应章节？练习答案是教学要点，不代替自己的推导或实验记录。
