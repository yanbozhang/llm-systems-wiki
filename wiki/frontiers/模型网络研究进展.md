## MoSE：专家被选中后，也不必总是完整执行

MoSE列入ICML 2026官方目录。作者在专家内部使用共享参数的嵌套子网络：路由器选择专家，宽度参数决定该专家的中间维度。训练需要让多个宽度共同工作，不能把普通MoE的矩阵临时裁窄就当成已训练好的MoSE。本轮读到arXiv v2的机制与训练目标。[录用记录](../../sources/library/2026-paper-network-mose/README.md) · [论文正文与版本](../../sources/library/2026-full-network-mose/README.md)

对输入维度为d、FFN扩展比为4的论文设置，宽度w对应的中间维度为：

$$
m(w)=\lceil4dw\rceil,\qquad
W_{up}^{(w)}=W_{up}[:,:m(w)],\quad W_{down}^{(w)}=W_{down}[:m(w),:]
$$

这使小宽度和大宽度共享一个参数前缀。下面只估算两个矩阵乘的乘加次数MAC，不计激活、通信、路由、padding和内核启动；一次MAC也不等于一次FLOP。

```python
from math import ceil

def expert_macs(d, widths):
    if d <= 0 or any(not 0 < w <= 1 for w in widths):
        raise ValueError("维度为正，宽度位于(0,1]")
    return sum(2 * d * ceil(4 * d * w) for w in widths)

print(expert_macs(4, [0.5, 1.0]))  # 192 MAC
print(expert_macs(4, [1.0, 1.0]))  # 256 MAC
```

## RoBSA：用RoPE部分寻找值得精算的块

RoBSA是ACL 2026主会长文，研究MLA在解码阶段的稀疏计算。论文将MLA的内容分量与RoPE分量分开，用后者形成便宜的相关性代理，再选择块执行注意力；还需要逐层校准代理与完整分数的相似性。本轮读取了论文§2的分解、假设和算法设计。[录用记录](../../sources/library/2026-paper-network-robsa/README.md) · [论文正文](../../sources/library/2026-full-network-robsa/README.md)

$$
s_j=\frac{q_C^\top k_{C,j}+q_R^\top k_{R,j}}{\sqrt{d_C+d_R}},\qquad
\widehat{s}_j=\frac{q_R^\top k_{R,j}}{\sqrt{d_C+d_R}}
$$

C表示内容部分，R表示经过RoPE的位置部分；d_C和d_R是相应维度。论文比较的是这些分数经过softmax后的分布。下面用“块内最大代理分数”演示选择过程，仅用于理解块粒度，不复现论文完整的多头聚合、逐层校准及必须保留位置的策略。

```python
from math import sqrt

def proxy_blocks(query, keys, content_dim, block_size, keep_blocks):
    if not query or content_dim < 0 or block_size <= 0 or keep_blocks < 0:
        raise ValueError("维度、块大小和保留数量无效")
    if any(len(key) != len(query) for key in keys):
        raise ValueError("向量维度必须一致")
    scores = [sum(q * k for q, k in zip(query, key)) /
              sqrt(content_dim + len(query)) for key in keys]
    blocks = [max(scores[i:i + block_size])
              for i in range(0, len(scores), block_size)]
    return sorted(range(len(blocks)), key=lambda i: (-blocks[i], i))[:keep_blocks]

print(proxy_blocks([1, 0], [[1, 0], [0, 1], [-1, 0], [2, 0]], 2, 2, 1))
# [1]：选择第二个块，块内两个位置一起进入后续精算
```

```mermaid
    A[MLA查询与缓存] --> B[提取RoPE分量]
    B --> C[轻量代理分数]
    C --> D[逐层策略与块选择]
    A --> E[所选块的完整注意力]
    D --> E

```

代理遗漏的内容相关性可能很重要，因此不能把高平均相似度解释为每个token都安全。论文针对MLA与长上下文解码的结论，也不能直接移植到任意MHA模型或prefill阶段。复核时至少同时保留层、上下文长度、选择预算和任务分数。
